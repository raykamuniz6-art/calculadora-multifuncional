# Calculadora Multifuncional

## Objetivo

Desenvolver uma calculadora multifuncional utilizando o Flowgorithm,
com diferentes operações matemáticas e um menu interativo.

## Integrante

- RAYKA LETICIA MUNIZ DOS SANTOS

## Funções disponíveis

1. Adição
2. Subtração
3. Multiplicação
4. Divisão
5. Potenciação
6. Resto da divisão
7. Média
8. Área do círculo
9. Fatorial
10. Porcentagem
11. Encerrar

## Funcionamento

O programa apresenta um menu com as operações disponíveis.
O usuário escolhe uma opção e informa os valores necessários
para realizar o cálculo.

Após cada operação, o programa retorna ao menu principal.
A opção 11 encerra a execução.

## Estruturas utilizadas

- Variáveis
- Entrada de dados
- Saída de dados
- Estrutura condicional `Se`
- Estrutura de repetição `Enquanto`
- Atribuições

## Ferramenta utilizada

Flowgorithm
