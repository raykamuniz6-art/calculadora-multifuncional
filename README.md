# Calculadora Multifuncional

## Objetivo

Desenvolver uma calculadora multifuncional utilizando o Flowgorithm,
com diferentes operações matemáticas e um menu interativo.

## Integrante

- RAYKA LETICIA MUNIZ DOS SANTOS

## Funções disponíveis

## Funções disponíveis
1. **Adição**: Realiza a soma de dois números.
2. **Subtração**: Realiza a subtração entre dois números.
3. **Multiplicação**: Realiza a multiplicação de dois números.
4. **Divisão**: Realiza a divisão entre dois números (com validação para não dividir por zero).
5. **Potenciação**: Calcula a potência de um número elevado a outro.
6. **Resto da divisão**: Retorna o resto (módulo) da divisão inteira.
7. **Média**: Calcula a média aritmética dos valores informados.
8. **Área do círculo**: Calcula a área com base no raio fornecido.
9. **Fatorial**: Calcula o fatorial de um número inteiro.
10. **Porcentagem**: Realiza cálculos de base percentual.

## Funcionamento
O programa apresenta um menu interativo com as operações disponíveis e conta com **tratamento para opções inválidas**, impedindo que o sistema trave caso o usuário digite um número incorreto. 

O usuário escolhe uma opção e informa os valores necessários para realizar o cálculo. Após cada operação, o programa retorna ao menu principal através de um loop. A **opção 11 encerra a execução** do programa definitivamente.

## Estruturas utilizadas
* **Variáveis**: Armazenamento temporário dos dados de entrada e resultados.
* **Entrada e Saída de dados**: Interação com o usuário via console.
* **Estrutura condicional Se (If/Else)**: Utilizada para identificar a opção selecionada no menu e validar restrições (como divisão por zero).
* **Estrutura de repetição Enquanto (While)**: Mantém o menu em execução contínua até o comando de encerramento.
* **Atribuições**: Definição de cálculos e passagem de valores para as variáveis.
